# Support

Use the channel that matches the request:

- Questions and usage help: [GitHub Discussions](https://github.com/Johnkothapalli/python-code-health-analyzer/discussions)
- Reproducible defects: [bug report](https://github.com/Johnkothapalli/python-code-health-analyzer/issues/new?template=bug.yml)
- Rule proposals: [rule proposal](https://github.com/Johnkothapalli/python-code-health-analyzer/issues/new?template=rule.yml)
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md)

Please include the analyzer version, Python version, command, smallest safe reproduction, and
relevant output. Support is provided by the community on a best-effort basis.
